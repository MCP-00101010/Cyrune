# ScummVM game metadata

`games.xml`, `companies.xml`, and `series.xml` are unmodified copies from the
[ScummVM icon database](https://github.com/scummvm/scummvm-icons/tree/fcf8c4ca51f9406e858e301ab66b511b5d3bed0b/default),
revision `fcf8c4ca51f9406e858e301ab66b511b5d3bed0b`, added 2026-09-07.
See `LICENSE.txt` (GPL-2.0) and `AUTHORS.txt`.

Arcade resolves publisher (`company_id`) and series (`series_id`) using exact
ScummVM engine/game IDs. It does not guess from titles or interpret an absent
series as an error. The snapshot is local and makes no runtime network requests.
Its display metadata does not change import manifests, native targets, or approvals.
